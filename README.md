# 小三常識溫習樂園

為小學三年級學生而設的常識科溫習網站，涵蓋三課：

| 課次 | 單元 | 課題 |
|---|---|---|
| 3.1 第4課 | 單元二 身心健康 | 我的好朋友 |
| 3.2 第3課 | 單元二 植物萬花筒 | 香港的植物 |
| 3.2 第4課 | 單元二 植物萬花筒 | 植物與生活 |

## 內容
每課包括：
1. **課文總結** — 重點用顏色標示，可廣東話朗讀
2. **供詞填充** — 點詞語再點空格
3. **按圖選擇**
4. **短答**
5. **是非題**
6. **圖片填充** — 直接在圖上填寫各部分名稱
7. **短答題** — 可對照參考答案
8. **場景問答（是非及選擇題）**
9. **成績表** — 星級、正確率、各項表現

## 技術
純靜態網頁（HTML / CSS / Vanilla JS），無外部依賴；所有插圖以手繪 SVG 製作。
進度以 localStorage 儲存，可離線使用。

```
index.html      首頁（進度總覽）
lesson.html     課題頁（?id=1|2|3）
css/style.css
js/pics.js      SVG 插圖庫
js/lesson1-3.js 課題內容與題目
js/engine.js    題目引擎（出題、批改、計分）
```

## 說明
根據《今日常識 新領域》小三溫習簡報的重點重新編寫，僅供學習用途。
